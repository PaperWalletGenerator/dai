## 🔐 Why a Paper Wallet for DAI?

In 2024, browser extensions, mobile wallets, and exchanges have become increasingly vulnerable to phishing, bugs, and centralized risks.

So here's what I do:

- ✅ Generate keys **completely offline**
- ✅ Print them on **archival-quality paper**
- ✅ Laminate + store them in a **fireproof vault**
- ✅ No browser plugins, no cloud backups, no "forgot password" buttons
